# Ipon 10 Judo – izdanja

Android aplikacija za praćenje takmičara SU „Ipon 10", Pirot (podaci sa judo.rs i live.judo.rs).

**Preuzimanje:** otvorite [poslednje izdanje](https://github.com/nesa03077-del/ipon10-judo-releases/releases/latest)
i preuzmite `.apk` fajl na telefon.

Instalirana aplikacija sama proverava nove verzije: **Podešavanja → Ažuriranje aplikacije → Proveri ažuriranja**.
